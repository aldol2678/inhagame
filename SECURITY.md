# Security

Do not publish credentials, personal data or exploit details in public issues.
Use a maintainer-confirmed private reporting channel before sharing sensitive findings.
A verified reporting inbox is not supplied by this local package.

The included database is for local disposable development. All example account identifiers are synthetic.
Retired token/digest OPS authentication must always reject credentials. Account authorization is server-side.
Never attach production secrets, privileged runners, cloud OIDC trust or deployment hooks to this package.
