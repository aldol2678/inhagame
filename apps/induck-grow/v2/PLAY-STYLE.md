# 플레이스타일 1차 구현

플레이스타일은 조작량과 정보 표시를 바꾼다. 별도 난이도나 보상 배율을 만들지 않는다.

- 기본: 기존 생활 방침, 학기 전공 활동, 주간 생활 활동을 직접 선택한다. 새 게임의 기본값이다.
- 간편: 생활 방향과 주간 자동 생활 활동 한도를 정하면 현재 상태를 보고 다음 주 계획을 제안하고, 사용자가 진행할 때 기존 엔진의 선택 API로 실행한다.
- 상세: 이번 패치에서는 펼쳐 보는 계획 근거·선택 이력이다. 독립 시뮬레이션 모드가 아니다.
- 정밀: 후속 범위이며 실행할 수 없는 선택 버튼을 만들지 않는다.

## 간편 계획

미리보기는 상태나 RNG를 변경하지 않으며 seed/rngState를 읽지 않는다. 미래 사건, 성적, 수입을 미리 시뮬레이션하지 않는다.

1. 체력 45 미만 또는 스트레스 60 이상이면 균형 방침과 회복 활동을 우선한다.
2. 그 외에 생활비 18,000원 미만이면 아르바이트 방침에 집중한다.
3. 나머지는 사용자의 생활 방향을 따른다. 학기 첫 주에만 전공 활동을 고르며, 진행 중인 학기 활동은 유지한다.
4. 주간 한도는 0 / 6,000 / 10,000 / 15,000원이며 기본값은 0원이다. 기존 생활 활동 중 한 번만 선택한다. 사용하지 않은 한도는 다음 주로 이월하지 않는다.
5. 유료 활동은 지금 가진 생활비로 살 수 있고 활동 직후 18,000원이 남는 경우에만 선택한다. 이는 이후 기본 생활비·방침 비용·사건 결과까지 포함한 주말 잔액 보장이 아니다.

한도는 선택형 생활 활동 비용만 제한한다. 기존 주간 기본 생활비, 방침에 따른 지출, 직접 고르는 사건 결과는 별도다. 무료 활동에도 기존 50% 시간 사용 규칙과 반복 효과가 그대로 적용된다.

## 사건과 설정 변경

중요한 사건은 간편에서도 반드시 직접 고른다. 사건 대기 중에는 주차·활동 비용·보상이 진행되지 않는다. 사건 전에 준비한 간편 계획은 저장되어 그 주가 끝날 때까지 잠긴다. 이때 플레이스타일·한도·방향을 변경하면 다음 주부터 반영된다. 잠긴 계획과 현재 설정이 다른 경우 화면에 둘을 구분해 보여 준다. 사건 결과로 잔액이 부족해지면 기존 엔진이 유료 활동을 결제 없이 취소한다.

플레이스타일, 한도, 방향 변경 자체는 주차 진행이나 보상을 만들지 않는다. 기본에서 같은 방침·활동·사건 선택을 하면 같은 엔진 결과가 나온다.

## 저장과 기록

- 기존 저장 키와 스키마를 유지한다. playStyle 메타데이터가 없는 저장은 기본으로 이어지고, 불러오기만 해서는 새 필드를 쓰지 않는다.
- 기존 저장에 간편을 켜도 전공 성장이나 생활 활동 기능을 몰래 추가하지 않는다.
- playStyle.startedAt 이후 완료한 주마다 모드, 실제 방침·전공 활동·생활 활동·비용과 해당 계획의 한도를 기록한다. 사건 선택 이력은 기존 memories에 유지한다.
- 미완료 계획이나 모드 토글만으로 자동 사용 주차가 늘지 않는다. 기록실은 실제 간편 완료 주차가 하나라도 있는 기록을 표시하고 순위 그룹을 분리한다.
- 이것은 브라우저 로컬 기록이다. 자동 사용 표시는 보안 검증·서버 인증·공정한 온라인 순위의 증거가 아니다.
- 알 수 없는 버전이나 불일치 이력은 원본을 덮어쓰지 않고 불러오기를 실패 처리한다.
