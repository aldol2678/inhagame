# apps

Game applications in the INHAGAME universe live here.

- `classic/`: 인하오리 Classic
- `induckup/`: 인덕업 (Induck Up)
- `survival/`: 인덕 서바이벌 (Inha Duck Survival)
- `induck-grow/`: 인덕이 키우기
- `world/`: INHA WORLD (게임 허브 / 가상 캠퍼스, served under `/campus/`)
- `shared/`: client configuration shared by the apps

The shared Supabase backend lives at the repository root under `supabase/`.
Deployment configuration and Production hosts are maintained outside this repository
(see the root README, "Public / Production Boundary").
