# INHA WORLD · 인하대학교 CI 및 상표 사용 가드

상태: 현재 구현 가드  
기준일: 2026-10-06  
대상: INHA WORLD 웹 허브 및 3D 캠퍼스

## 현재 운영 전제

- 학생 주도 창작 프로젝트로 운영한다.
- 누구나 무료로 이용할 수 있다.
- 광고, 유료 아이템, 구독, 판매, 후원·협찬 등 프로젝트 수익화를 현재 운영 전제로 두지 않는다.
- INHA WORLD / INHAGAME의 독립 브랜드를 서비스의 주 브랜드로 유지한다.

## 인하대학교 CI 사용 범위

다음 범위의 제한적 사용을 허용 범위로 취급한다.

- 실제 캠퍼스 건물에 존재하는 교표·학교 표지를 캠퍼스 재현 목적으로 표현
- 게임 내 지도·안내판 등에서 캠퍼스 및 학교 정보를 설명하기 위한 제한적 CI 사용
- 공식 CI의 형태, 비율, 색상을 임의로 변형하지 않는 사용

다음 사용은 피한다.

- 인하대학교가 INHA WORLD를 직접 제작·운영·후원하는 공식 서비스로 오인될 수 있는 표현
- INHA UNIVERSITY 워드마크나 교표를 INHA WORLD 자체의 서비스 로고처럼 사용하는 구성
- CI의 왜곡, 임의 조합, 임의 색상 변경

## 필수 고지

웹 허브와 게임 내 적절한 위치에 다음 문구를 유지한다.

> INHA WORLD는 인하대학교가 공식적으로 제작·운영·후원하는 서비스가 아닌 학생 창작 프로젝트입니다.

인하오리 Classic에는 기존 비공식 제작 서비스 고지가 별도로 존재한다.

## 수익화 변경 Gate

광고, 유료 아이템, 구독, 판매, 후원·협찬 등 프로젝트를 통한 수익이 발생하는 방식으로 운영이 변경되기 전에는 인하대학교 상표 사용 조건을 다시 확인하고 필요한 사용 신청·문의를 선행한다.

이 문서는 프로젝트 내부 구현 가드이며 법률 자문서나 포괄적 상표 라이선스를 대체하지 않는다.
