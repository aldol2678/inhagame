# INHAGAME Hub P0 concept artwork

All five SVGs were created for the **Hub visual design concept** in this project, extracted from the approved draft prototype `inhagame_hub_redesign_mockup.html`.

- `campus-concept.svg`: illustrative campus atmosphere, **not** a capture of playable INHA WORLD or an authoritative rendering of real campus architecture.
- Four `*-concept.svg` posters: original visual placeholders for current catalog games, **not** official gameplay screenshots.
- Avoid using protected school logos or representing the product as officially operated/endorsed by Inha University.
- These lightweight static SVGs need no client JS, WebGPU or additional dependencies.
- Replace only after verifying authentic captures, provenance and permission; retain the existing game catalog and link gate.

Status: `DRAFT_UI_ART`. No claim of university approval or production gameplay visual parity.
